## Featured: Veron

Veron is a point-of-sale and business management system for bars.
It runs in production at a bar in Pune.
Veron handles billing.
It tracks inventory.
It manages staff roles.
It records customer credit (udhaar).

**Stack:** Flutter · Dart · Supabase · PostgreSQL

[Website](https://aditya-bhoye.github.io/Veron/) · [Repository](https://github.com/Aditya-Bhoye/Veron)
